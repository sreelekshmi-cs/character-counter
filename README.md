Character Counter

About

A simple Character Counter web application built using HTML, CSS, and JavaScript.

Features

- Real-time character counting
- Maximum limit of 200 characters
- Remaining character display
- Warning message when the character limit is reached
- Green progress bar to visualize character usage
- Simple and user-friendly interface

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Open the application in your browser.
2. Type a message in the text area.
3. View the typed characters and remaining characters in real time.
